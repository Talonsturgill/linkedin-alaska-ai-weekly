# Art plan: THE STACK / VEHICLES / 5 OCT 2026

**Story.** DOE announced an *intent to deploy* up to $150M of Defense Production Act money for AEA's 223-mile Beluga-Healy line. Nothing is obligated. One officer, the Secretary of Energy, owns the yes/no that closes the circuit. Register: tense, held-breath, poised. Expectant not alarmed.

**Dedup scan.** Last 8 stack styles: still_life_gouache, machined_plate, woven_fabric, exploded_iso_docket, riso_form, hydrographic_claim, voronoi_impoundment, organic_rd_moorage (+ ukiyo_bokashi, geologic_engraving). Hues last 4: red, violet, gold, blue. Compositions last 2: column_and_icon, suspended_gap. Motifs to avoid: hourglass, coupling gap, loom, docket lid, forms.

**Three concepts.** (1) Pylons marching over a ridge with the last span dashed. Killed: reads like 9/21 gap piece. (2) A funnel of rays from Washington into a single valve. Generic. (3) **A knife switch (disconnect), blade raised, set against a ridge of lattice pylons.** Binary = open/closed, literally electrical, scale contrast with the 223-mile line behind. CHOSEN.

**Concept statement.** A giant open knife switch in the foreground, blade swung up in orange, the Beluga-Healy pylon line marching small along the ridge behind it. The money is announced, the circuit is not closed.

**Style family.** constructivist (diagonal thrust, hard wedges, rays, cream/dark/accent) hybridised with a technical-drawing finish. Unused for 8+ issues. Hue family teal (not in last 4).

**Palette (value spine).** paper #eee5d0 (L .93), pale teal #bcd3c8, field teal #2f7c78 (L .52), shadow teal #14403f (L .30), ink #0b1a1b (L .15), copper #c8743a (jaw contacts), signal orange #ff5f1f focal accent (highest chroma, only warm saturated mass). Focal blade wins on hue and on value against pale sky; ink slab anchors the bottom.

**Composition map: diagonal_thrust (knife_switch_diagonal).** Grid 1080.
- Headline block left-aligned x=72, top y=64, Fraunces 900, 4 lines @ ~70px, leading 1.04; kicker mono y=372.
- Hinge terminal (330, 716); blade length 410 at 52 deg up-right, tip (582, 393) with insulated ring handle r=24.
- Left insulator column x=330, y 716..842. Right jaw column x=850, y 716..842. Base slab x 190..990, y 842..940 (ink). Left feed wire from hinge to (130, 640) up to left edge; right wire from jaw to right edge rising to far pylon line.
- Ridges: far y0~560 (tilted rising right), mid 640, near 735 (behind switch). Pylon line on mid ridge x=60..1040, 11 towers, 38-62px high, conductors sagging.
- Quiet sky zone upper right x 640..1010 y 120..360: pale rays from hinge, wordmark bottom-left (96, 1000) on slab? wordmark inside slab at (222, 892). Polaris (990, 84) r=15.
- Eye path: headline -> blade tip ring -> blade diagonal down to hinge -> pylon line to the right horizon.

**Layer build order.** paper -> mottle -> faint rays -> sky wedge -> far ridge -> mid ridge + towers/conductors -> near ridge + stipple/chips snow -> ground fog band -> feed wires -> base slab + bolts + hatching -> insulators -> terminals/jaw -> blade + handle -> spark ticks at jaw -> labels -> headline -> marks -> grain.

**Technique stack.** ridge_pts/ridge_fill, hand_line, poly, hatch/stipple masks, rays, chips, mottle(0.05), grain(6), fraunces/mono text, polaris.

**Labels (from dossier only).** Left terminal tag "INTENT TO DEPLOY / UP TO $150M", right tag "NON-FEDERAL / $268M". Caption on slab: "SEC. OF ENERGY".

**Risks.** (1) Blade tip colliding with headline: tip kept at y>=393 below kicker. (2) Mid-tone mud between teal ridges: keep 3-step lightness ramp and ink slab. (3) Switch reading as generic clip-art: add machined detail (ribbed insulators, bolt heads, copper jaw, shadow), scale of pylons proves it is a metaphor.
